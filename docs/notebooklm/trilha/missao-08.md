# Missão 8. Aprenda Git e GitHub desde o início

Git: guarda a memória das mudanças. GitHub: hospeda e compartilha o repositório.

## Parte A — criar sua conta

- Abra github.com/signup.
- Informe seu e-mail.
- Crie uma senha forte e exclusiva.
- Escolha um nome de usuário que você consiga lembrar. Evite telefone, documento ou endereço.
- Abra o e-mail de verificação e digite o código somente no site github.com.
- Entre na conta e ative a autenticação em dois fatores. Peça apoio se esta parte parecer difícil.
- Não publique ainda. Primeiro faça a missão de segurança.

## Parte B — entender antes de clicar

- Mostre onde aparecem o nome do repositório, os arquivos e o README.md.
- Aprenda cinco cartões: arquivo, repositório, commit, branch e push.
- Crie um repositório ou use o repositório preparado para a turma.
- Mude uma frase pequena e veja o antes e o depois.
- Revise a lista de arquivos. Pare se aparecer .env, token, banco local, foto ou dado pessoal.
- Escreva uma mensagem de commit que diga o que mudou e por quê.
- Envie a mudança. Depois confira no site do GitHub.

Frases para eu explicar: “Meu repositório guarda ___. Meu commit mostra ___. Eu não publiquei ___ porque ___. Usei uma branch quando ___.”

Explique: o que a “fotografia da mudança” guarda e por quê?

Atenção: Peça uma revisão antes da primeira publicação
