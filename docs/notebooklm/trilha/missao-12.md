# Missão 12. Planeje o bot do Telegram

Meta: desenhar uma conversa segura entre pessoa, programa e resposta.
Faça: planeje /start, /ajuda e um comando do projeto, usando dados fictícios.
Depois, crie e teste o bot seguindo o tutorial oficial. Peça ajuda para configurar servidor e variáveis de ambiente.
Documentos: telegram/comandos.md e telegram/testes.md.

Atenção: Token é senha: nunca aparece no site ou no GitHub
