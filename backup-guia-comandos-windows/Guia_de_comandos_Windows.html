Guia de comandos do Windows

Referência prática para usar o PowerShell e o Prompt de Comando. Reúne criação, organização, abertura e exclusão de arquivos, além de pesquisa, compactação e consultas do sistema. Escolha sua coluna e execute um comando por vez.

Como abrir o terminal: procure PowerShell ou Prompt de Comando no menu Iniciar. Para as operações comuns na sua pasta pessoal, não é necessário executar como administrador. O Windows Terminal também pode abrir esses ambientes em abas.

Como usar os exemplos: troque os nomes de exemplo pelos seus. Coloque caminhos com espaços entre aspas. Um caminho como C:\Projetos\Aula é completo; notas.txt aponta para a pasta atual. No CMD, > substitui o conteúdo e >> acrescenta ao final.

Começar e navegar

O Windows Terminal é a janela que pode abrir PowerShell ou Prompt de Comando. Use a coluna correspondente à sua aba. Não copie o prefixo PS C:\...> ou C:\...> que aparece antes do comando.

Criar pastas e arquivos

As pastas e arquivos são criados no local atual, salvo quando você informa um caminho completo. Os comandos que escrevem conteúdo abaixo substituem o conteúdo de um arquivo existente.

AçãoPowerShellCMD

Criar arquivo vazio New-Item -ItemType File -Path "notas.txt" type nul > "notas.txt"

Acrescentar uma linha ao final 'Outra linha' | Add-Content -Path "notas.txt" -Encoding utf8 echo Outra linha >> "notas.txt"

Abrir ler e fechar documentos

Abrir com o aplicativo padrão depende de haver um programa associado à extensão. Para salvar, use Ctrl + S no aplicativo. Para fechar a janela, use Alt + F4; no Word, Ctrl + W fecha o documento atual. O aplicativo pode pedir para salvar as alterações.

Ler um arquivo longo por partes Get-Content "notas.txt" | more more "notas.txt"

Abrir um site no navegador padrão Start-Process "https://www.microsoft.com" start "" "https://www.microsoft.com"

Copiar mover e renomear

Nos exemplos de movimentação, a pasta Destino deve existir. Copiar ou mover para um nome já existente pode substituir arquivos ou pedir confirmação. Para copiar pastas, robocopy /E inclui subpastas vazias; não use /MIR sem entender que ele pode apagar itens no destino.

Renomear uma pasta Rename-Item "Antiga" "Nova" ren "Antiga" "Nova"

Excluir arquivos e pastas

A exclusão pelo terminal não envia os itens à Lixeira. Antes de excluir uma pasta inteira, confira a pasta atual e liste o conteúdo do caminho de destino. Os comandos abaixo usam nomes de exemplo; substitua apenas pelo caminho que deseja excluir.

AçãoPowerShellCMD
Excluir um arquivo Remove-Item -LiteralPath "arquivo.txt" del "arquivo.txt"
Excluir pedindo confirmação Remove-Item -LiteralPath "arquivo.txt" -Confirm del /p "arquivo.txt"
Excluir uma pasta vazia Remove-Item -LiteralPath "Pasta Vazia" rmdir "Pasta Vazia"
Excluir pasta e todo o conteúdo Remove-Item -LiteralPath "Minha Pasta" -Recurse -Confirm rmdir /s "Minha Pasta"
Simular a exclusão sem apagar Remove-Item -LiteralPath "Minha Pasta" -Recurse -WhatIf Não há equivalente direto; confira com dir "Minha Pasta" /s

Pesquisar arquivos e textos

O asterisco representa uma sequência de caracteres. Por exemplo, *.pdf seleciona nomes terminados em .pdf. As buscas recursivas percorrem as subpastas e podem demorar em pastas grandes.

AçãoPowerShellCMD
Listar os PDFs da pasta atual Get-ChildItem -Filter *.pdf -File dir *.pdf /b /a-d
Buscar PDFs nas subpastas Get-ChildItem -Filter *.pdf -File -Recurse dir *.pdf /s /b /a-d
Buscar um arquivo pelo nome Get-ChildItem -Filter "relatorio.docx" -File -Recurse dir "relatorio.docx" /s /b /a-d
Buscar palavra dentro de texto Select-String -Path "notas.txt" -Pattern "palavra" -SimpleMatch findstr /i /n /c:"palavra" "notas.txt"
Ver se um caminho existe Test-Path "notas.txt" if exist "notas.txt" (echo Existe) else (echo Nao existe)

Ajuda e encerramento de aplicativos

Prefira fechar documentos pela janela do aplicativo. Encerrar um processo pode perder alterações não salvas e afetar vários documentos. Os exemplos por nome atingem as instâncias correspondentes do Bloco de Notas; eles não selecionam um documento específico.

AçãoPowerShellCMD
Consultar ajuda de um comando Get-Help Copy-Item -Examples copy /?
Ver comandos disponíveis Get-Command help
Consultar histórico da sessão Get-History doskey /history
Encerrar o Bloco de Notas Stop-Process -Name notepad taskkill /IM notepad.exe

Atalhos importantes

  • Tab completa nomes de arquivos, pastas e comandos conforme o terminal.
  • Setas para cima e para baixo percorrem os comandos anteriores.
  • Ctrl + C interrompe o comando em execução quando não há texto selecionado.
  • Ctrl + Shift + C e Ctrl + Shift + V copiam e colam no Windows Terminal. Em outras janelas, os atalhos podem depender das configurações.
  • Ctrl + S salva o documento no aplicativo; não é um comando do terminal.
  • Ctrl + W fecha o documento atual no Word; em outros programas, depende do aplicativo.
  • Alt + F4 fecha a janela ativa.

Exemplo completo no seu projeto

No PowerShell, execute estas linhas uma por vez para criar uma pasta de prática, criar o arquivo JSON e abri-lo no Bloco de Notas. A linha de gravação substitui o conteúdo caso o arquivo já exista.

cd "C:\Users\rcmin\Projetos\Aula_03"
mkdir "Pratica Terminal"
cd "Pratica Terminal"
'{}' | Set-Content -Path "settings.local.json" -Encoding utf8
notepad "settings.local.json"

Depois de editar, use Ctrl + S para salvar e Alt + F4 para fechar o Bloco de Notas. Para conferir o conteúdo no PowerShell:

Get-Content "settings.local.json"

Detalhes que evitam erros

  • No comando start "" "documento.docx", as primeiras aspas vazias reservam o título da janela no CMD.
  • New-Item sem -Force normalmente retorna erro se o arquivo já existir. Já Set-Content e o redirecionamento > substituem conteúdo.
  • No Windows PowerShell 5.1, -Encoding utf8 grava uma marca BOM; no PowerShell 7, grava UTF-8 sem BOM. Se um programa rejeitar o JSON, salve-o em UTF-8 sem BOM no editor.
  • Remove-Item numa pasta não vazia sem -Recurse pode pedir confirmação. Para conferir sem apagar, use -WhatIf.
  • Use buscas com * para localizar arquivos, mas confira cuidadosamente qualquer curinga em comandos de exclusão.
  • Se aparecer “acesso negado”, confira o caminho, as permissões e se o arquivo está aberto em outro programa.
