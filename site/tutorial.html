O projeto é escrito em Python. O Gemini só consegue rodar o código se o Python estiver instalado. Primeiro confira. Se faltar, instale.

A) Conferir o que você já tem

Abra o terminal: tecla Windows, digite PowerShell, Enter. Digite os três comandos, um de cada vez:

Uma versão do gitO Git está instalado. Você só vai usar no final.
"não é reconhecido"Falta instalar, ou o PATH não foi marcado.

Pedido: conferir as ferramentas

B) Instalar o Python (se faltar)

  1. Abra python.org/downloads.
  2. Clique no botão amarelo Download Python. Prefira a versão 3.12 (ou 3.11). Versões muito antigas deixam de receber correções. Por isso não use uma anterior à 3.11.
  3. Abra o arquivo baixado.
  4. Marque a caixinha "Add python.exe to PATH" (embaixo, na primeira tela).
  5. Clique em Install Now e espere terminar.
Outro jeito, se o seu Windows tiver o winget: no PowerShell, digite o comando abaixo.
winget install Python.Python.3.12

C) Fechar e abrir de novo

Depois de instalar, feche o PowerShell e o Antigravity e abra os dois de novo. Eles só enxergam o Python que foi instalado antes de abrirem.

Abra um terminal novo e repita python --version.

D) Instalar o Git (se faltar)

O Git guarda as versões da sua pasta e só será usado no final. Você pode instalar agora ou na Etapa 6 do manual.

  1. Abra git-scm.com/download/win e baixe o instalador.
  2. Abra o arquivo e clique em Next até o fim. As opções padrão servem.
  3. Feche e abra o terminal. Confira com git --version.
Continua dizendo "não é reconhecido"? Você esqueceu a caixinha Add python.exe to PATH. Rode o instalador de novo, escolha Modify e marque Add to environment variables. Depois feche e abra tudo de novo. Ainda não deu? Chame o professor.
Você não precisa instalar o Node.js. Este projeto usa só Python e HTML. Se o assistente sugerir node ou npm, responda: "Use só Python e HTML, sem Node."

E) Teste o Python de verdade

Ver a versão não basta. Rode um programinha seu. No PowerShell, digite:

python -c "print('Olá, oficina!')"

Deve aparecer Olá, oficina!. Agora instale uma peça de teste e use:

python -m pip install requests
python -c "import requests; print(requests.__version__)"

Apareceu um número de versão? O pip funciona. Você vai usar isso na API.

5Criar a API e ligar

A API é o programa que recebe os chamados e guarda no banco de dados. Ela precisa ficar ligada para o site funcionar.

Pedido da API

Agora crie só a API, numa pasta chamada "api", com Python e FastAPI.
- Banco de dados SQLite, num arquivo.
- POST /chamados: recebe nome (mínimo 2 letras), contato (mínimo 5), equipamento (mínimo 2) e relato (mínimo 10, máximo 1000). Responde com {"numero": N, "status": "aberto"}.
- GET /chamados/{numero}: devolve {"numero", "equipamento", "status", "prioridade", "laudo", "data"}. NÃO devolva nome nem contato. Enquanto o laudo não estiver pronto, "laudo" vem vazio (null). Se o número não existir, responda 404.
- Use EXATAMENTE esses nomes de campo: o site do projeto depende deles.
- Status possíveis: aberto, em_andamento, concluido.
- Libere CORS para uso local.

Crie o arquivo requirements.txt. Depois me diga, passo a passo, como criar o ambiente virtual, instalar as peças e ligar a API, e o que devo ver no terminal. Peça minha permissão antes de rodar qualquer comando.

6Criar a triagem e ver o site funcionando

A triagem faz o laudo. Ela usa o grafo: a memória da oficina, que liga aparelho → sintoma → causa → peça.

Pedido da triagem com o grafo

Agora crie a triagem com um grafo de conhecimento, em Python simples, que funcione SEM internet e SEM chave.

O grafo liga aparelho, sintoma, causa e peça. Use exatamente estes sete casos:
1. Dell G15 | desliga sozinho | pasta térmica de fábrica ressecada e aletas obstruídas | Pasta Térmica Alta Condutividade, Thermal Pads
2. Dell G15 | não liga | curto no circuito de carga (MOSFET de entrada) | MOSFET Canal N 30V, Carregador 130W
3. Acer Nitro 5 | tela azul | oxidação nos contatos da memória RAM | Limpa Contato Isopropílico, Memória DDR4
4. Acer Nitro 5 | tela preta | cabo flat da tela rompido ou solto na dobradiça | Cabo Flat EDP Nitro 5
5. MacBook Air | bateria não carrega | ciclos da bateria esgotados ou conector oxidado | Bateria Original A1466
6. Desktop | reinicia em jogos | fonte genérica sem potência suficiente | Fonte ATX 600W 80 Plus
7. Notebook | lentidão extrema | HD mecânico antigo com setores ruins | SSD NVMe 500GB ou SATA

Depois que um chamado é criado, faça o laudo em segundo plano: procure o aparelho e as palavras do relato no grafo.
- Se achar um caso: prioridade "alta" quando o relato tiver "não liga" ou "desliga", senão "media". Use a causa e as peças do caso.
- Se não achar: prioridade "media" e causa "necessário teste detalhado na bancada".

7Criar a automação em Python

A automação é um segundo robô, de reserva. Ele procura chamados que ficaram sem laudo e completa.

Para que serve

Imagine um funcionário que, de tempos em tempos, olha a fila e pergunta: "tem chamado sem laudo?". Se tiver, faz o laudo. Se não tiver, avisa que está tudo em dia. É um programa que repete uma verificação, sem ninguém mandar. Esse tipo de programa se chama laço (loop).

IdeiaQuer dizer
LaçoO programa repete a mesma coisa sem parar.
Espera de 5 segundosEntre uma verificação e outra, ele descansa. Sem isso, travaria o computador.
Terminal separadoA API já ocupa um terminal. A automação precisa de outro, ao lado.

Pedido da automação

Crie a automação em Python, um programa separado, de reserva.
A cada 5 segundos ela procura chamados SEM laudo e preenche o laudo usando a mesma triagem com grafo. Se não houver nenhum, escreve "Nenhum chamado pendente no momento". Deve parar com Ctrl + C.
Explique como ligar, em um terminal separado.
  1. Cole o pedido e aceite o que fizer sentido.
  2. Ligue a automação num segundo terminal, como o assistente explicar. Deixe a API ligada no primeiro.

Veja a automação trabalhando

  1. Deixe a automação ligada.
  2. No site, abra um chamado novo.
  3. Olhe o terminal da automação. Se a API já fez o laudo, ela continua dizendo que não há pendentes. É o esperado.
Parou de responder? Veja se a API ainda está ligada no outro terminal. Se a automação ficou parada, feche com Ctrl + C e ligue de novo.
Deu certo se aparecer Nenhum chamado pendente no momento a cada 5 segundos. Isso é normal: como a API já faz o laudo na hora, quase nunca sobra chamado sem laudo.
Para parar a automação: Ctrl + C.
Deu erro ou travou? Copie a mensagem do terminal e escreva para o assistente: "Apareceu este erro. Explique em palavras simples e corrija passo a passo."
Ouça no NotebookLM: por que existe uma automação de reserva. Pergunte no seu caderno (Etapa 2 do manual): "Para que serve a automação de reserva e o que ela escreve quando não há chamado pendente?" Depois compare com o que o Gemini fez. Se forem diferentes, pergunte ao professor.
Comprovante: print do terminal da automação rodando.
8Criar o agente CrewAI no Google Colab (a dupla de especialistas)

O CrewAI junta dois agentes de IA: um atendente e um técnico. Este passo é opcional. Ele roda no Google Colab, um caderno de código na nuvem do Google. Você não instala nada no seu computador.

Entenda a ideia antes de começar

Pense numa oficina de verdade. O cliente chega e conta o problema. O atendente ouve e decide a urgência. Depois o técnico pega essa informação e diz o que fazer. O CrewAI faz o mesmo com duas IAs.

Peça do CrewAINa oficinaO que você escreve
AgenteCada funcionárioA função (role), o objetivo (goal) e a história (backstory): quem ele é e como trabalha.
Tarefa (task)A ordem de serviçoA descrição do que fazer e a saída esperada (expected_output): o formato exato da resposta.
Equipe (crew)A bancada todaQuem trabalha, quais tarefas e em que ordem. O comando kickoff dá a largada.
Ferramenta (tool)As ferramentas da bancadaDeixam o agente buscar na internet ou num banco. Aqui não usamos.
Dica de ouro: a tarefa vale mais que o agente. Escreva a tarefa com clareza, diga o formato da resposta e dê uma coisa por tarefa. Se você pede pesquisar, analisar e escrever tudo junto, o resultado piora.

#  Célula 2: ler a chave dos Segredos e criar o modelo
from google.colab import userdata
from crewai import Agent, Task, Crew, Process, LLM
llm = LLM(model="gemini/gemini-3.6-flash",
          api_key=userdata.get("GEMINI_API_KEY"))

#  Célula 3: os dois agentes
atendente = Agent(
    role="Atendente de triagem de uma oficina de informática",
    goal="Entender o relato do cliente e dizer a urgência: alta, média ou baixa",
    backstory="Você atende clientes há anos, fala simples e não inventa informação.",
    llm=llm)
tecnico = Agent(
    role="Técnico de bancada",
    goal="Sugerir a causa provável e os próximos passos",
    backstory="Você conserta notebooks há 10 anos e explica de forma direta.",
    llm=llm)

#  Célula 4: as duas tarefas e a equipe
t1 = Task(
    description="Leia o relato: {relato}. Diga a urgência e explique em uma frase.",
    expected_output="Duas linhas: 'Urgência: ...' e 'Motivo: ...'",
    agent=atendente)
t2 = Task(
    description="Com a urgência já definida, sugira a causa provável e 3 passos para: {relato}",
    expected_output="'Causa provável: ...' e uma lista de 3 passos curtos.",
    agent=tecnico, context=[t1])
equipe = Crew(agents=[atendente, tecnico], tasks=[t1, t2],
              process=Process.sequential)

#  Célula 5: rodar
resultado = equipe.kickoff(inputs={"relato":
    "Dell G15 esquenta muito e desliga sozinho quando eu jogo"})
print(resultado.raw)

9Criar o Rádio do Técnico (Telegram)

O bot manda os chamados para o seu celular e aceita comandos. Esta parte também é opcional. Aqui você usa duas informações secretas: o token do bot e o seu Id.

Entenda como funciona

O Telegram é um aplicativo de mensagens. Um bot é uma conta controlada por programa, não por pessoa. O seu programa em Python conversa com o bot, e o bot conversa com o seu celular.

PeçaPapel
@BotFatherO bot oficial do Telegram que cria bots novos e entrega o token.
TokenA senha do bot. Quem tem o token manda mensagens como o seu bot.
Id do chatO número da sua conversa. O programa só obedece a esse número, por segurança.
ComandosMensagens que começam com barra, como /abertos.
Por que o Id importa: qualquer pessoa pode achar o seu bot e mandar mensagem. Sem a checagem do Id, um estranho poderia ver chamados ou dar baixa neles. Por isso o bot só aceita o seu número.

A) Criar o bot e achar o token

  1. No Telegram, procure @BotFather (com selo azul de verificado). Envie /start.
  2. Envie /newbot.
  3. Digite o nome da oficina. Depois um usuário que termine em bot.
  4. No fim, o BotFather manda uma mensagem com o token: um texto longo com números, dois pontos e letras. Esse é o token.
  5. Abra a conversa com o seu bot e envie /start.
Perdeu o token? No @BotFather, envie /mybots, escolha o seu bot e procure API Token. Para gerar um novo, envie /token.

B) Achar o seu Id

O Id é um número que identifica a sua conversa. O bot só obedece a quem tem esse número.

  1. No Telegram, procure @userinfobot e envie /start.
  2. Ele responde com o seu Id (só números). Anote.
Prefere não usar outro bot? Peça ao Gemini um programa que mostra o seu Id quando você manda uma mensagem ao seu bot. Cole o pedido abaixo.
