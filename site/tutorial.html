Tutorial passo a passo

Construa o projeto com o Gemini

Você cria uma pasta, abre no Antigravity e pede ao Gemini, passo a passo, o site, a API, a triagem, a automação e o agente. Só no final leva a pasta para o GitHub.

0 de 10 passos feitos

Antes de começar, faça as Etapas 1 a 4 do manual. Depois, faça um passo de cada vez, na ordem. Quando terminar, marque a caixinha "Passo feito" no fim dele. Os passos 8 e 9 são opcionais.

Como este tutorial funciona

Você pede, o Gemini cria

Cada passo tem um pedido pronto com botão de copiar. Cole no painel do assistente.

Você lê e aprova

O assistente pode mudar arquivos e rodar comandos. Leia antes de aceitar.

Você confere

Todo passo diz "Deu certo se" e pede um comprovante simples.

Os passos

1Instalar o Python

O Python é a linguagem em que o projeto vai ser escrito. Você instala uma vez.

  1. Abra python.org/downloads.
  2. Clique no botão amarelo Download Python. Prefira a versão 3.12 (ou 3.11).
  3. Abra o arquivo baixado.
  4. Marque a caixinha "Add python.exe to PATH" (embaixo, na primeira tela).
  5. Clique em Install Now e espere terminar.

Abra o terminal: tecla Windows, digite PowerShell, Enter. Digite:

python --version
Deu certo se aparecer algo como Python 3.12.10.
Disse "python não é reconhecido"? Você esqueceu a caixinha PATH. Rode o instalador de novo, escolha Modify e marque Add to environment variables. Feche e abra o PowerShell.
Comprovante: print do terminal com a versão do Python.
2Conferir a pasta e o assistente

Você já fez a Etapa 1 do manual: criou a pasta oficina-digital e abriu no Antigravity. Confira antes de continuar.

  1. O Antigravity está aberto com a pasta oficina-digital.
  2. O painel do assistente aparece do lado direito do editor.
  3. O Gemini respondeu ao seu primeiro olá.
Leia antes de aceitar. O assistente pode propor mudar arquivos ou rodar comandos. Só aceite se você entender. Em dúvida, pergunte ao professor.
Nunca escreva senha, token ou chave no chat do assistente. O que você escreve vai para o Google. Se for colar um erro, apague antes qualquer chave que apareça nele.
Ficou com dúvida em algum passo? Pergunte no seu caderno do NotebookLM (Etapa 2 do manual). Ele explica em áudio.
Ainda não fez a Etapa 1? Volte ao manual e faça primeiro. Sem a pasta aberta no Antigravity, os próximos passos não funcionam.
Deu certo se o Antigravity abrir com a pasta e o Gemini responder.
Comprovante: print do Antigravity com a pasta aberta e o painel do assistente.
3Pedir o plano ao Gemini

Antes de criar qualquer coisa, peça um plano. Assim você entende o caminho e não se perde.

Pedido do plano

Sou aluno iniciante e leio pouco. Fale em frases curtas e palavras simples.

Vamos criar, nesta pasta, um projeto chamado Oficina Digital: uma oficina de conserto de computadores de mentirinha.
O cliente abre um chamado num site. Uma API em Python guarda o pedido. Uma triagem faz o laudo. O técnico recebe aviso no Telegram. O cliente acompanha o chamado no site.

As partes são: site (HTML, CSS e JavaScript), API (Python com FastAPI e banco SQLite), triagem com grafo de conhecimento, automação em Python, agente CrewAI com Gemini e bot do Telegram.

NÃO crie nenhum arquivo agora. Mostre só o plano, em passos curtos e na ordem certa, e a estrutura de pastas. Depois pergunte se pode começar.
  1. Leia o plano com calma. Se não entender algo, pergunte: "Explique a parte X de novo, mais simples."
  2. Quando estiver claro, responda: "Pode começar pelo site."
Quer ouvir sobre o projeto? Pergunte no seu caderno do NotebookLM (Etapa 2 do manual) e compare com o plano do Gemini.
Deu certo se o Gemini mostrar uma lista de passos e uma estrutura com as pastas site e api.
Comprovante: print do plano que o Gemini mostrou.
4Criar o site

O site é a vitrine: o cliente preenche o chamado e acompanha o andamento.

Pedido do site

Agora crie só o SITE, numa pasta chamada "site".

Uma página (index.html) com letra grande e fácil de ler.
- Formulário "Abrir chamado" com quatro campos: nome, contato (e-mail ou telefone), equipamento e relato do problema. Botão "Enviar chamado". Ao enviar, mostre o número do chamado.
- Área "Acompanhar": a pessoa digita o número e vê o status, a prioridade e o laudo.
- O site conversa com a API em http://localhost:8000 (POST /chamados e GET /chamados/{numero}). Se a API estiver desligada, mostre um aviso claro.

Explique cada arquivo em palavras simples. Ainda não crie a API.
  1. Cole o pedido no painel do assistente e aperte Enter.
  2. Leia o que ele vai criar. Aceite se entender.
  3. Na pasta site, dê dois cliques em index.html para ver no navegador.
Deu certo se a página abrir com o formulário e a área de acompanhar. O envio ainda não funciona: a API ainda não existe.
Deu erro ou travou? Copie a mensagem do terminal e escreva para o assistente: "Apareceu este erro. Explique em palavras simples e corrija passo a passo."
Comprovante: print do site aberto no navegador.
5Criar a API e ligar

A API é o programa que recebe os chamados e guarda no banco de dados. Ela precisa ficar ligada para o site funcionar.

Pedido da API

Agora crie só a API, numa pasta chamada "api", com Python e FastAPI.
- Banco de dados SQLite, num arquivo.
- POST /chamados: recebe nome (mínimo 2 letras), contato (mínimo 5), equipamento (mínimo 2) e relato (mínimo 10, máximo 1000). Responde com o número e o status "aberto".
- GET /chamados/{numero}: devolve equipamento, status, prioridade, laudo e data. NÃO devolva nome nem contato.
- Status possíveis: aberto, em_andamento, concluido.
- Libere CORS para uso local.

Crie o arquivo requirements.txt. Depois me diga, passo a passo, como criar o ambiente virtual, instalar as peças e ligar a API, e o que devo ver no terminal. Peça minha permissão antes de rodar qualquer comando.
  1. Cole o pedido. O assistente cria a pasta api e os arquivos.
  2. Ele vai pedir permissão para rodar comandos (criar o ambiente, instalar as peças, ligar a API). Leia cada um e aceite se entender.
  3. A API fica rodando no terminal. Não feche esse terminal. Para parar: Ctrl + C.
Deu certo se o terminal mostrar Uvicorn running on http://127.0.0.1:8000.
Quer ver a API por dentro? Abra no navegador http://localhost:8000/docs.
Disse que a porta 8000 está em uso? Outro programa usa essa porta. Peça ao assistente: "Troque a API para a porta 8001 e ajuste o site."
Deu erro ou travou? Copie a mensagem do terminal e escreva para o assistente: "Apareceu este erro. Explique em palavras simples e corrija passo a passo."
Comprovante: print do terminal com Uvicorn running.
6Criar a triagem e ver o site funcionando

A triagem faz o laudo. Ela usa o grafo: a memória da oficina, que liga aparelho → sintoma → causa → peça.

Pedido da triagem com o grafo

Agora crie a triagem com um grafo de conhecimento, em Python simples, que funcione SEM internet e SEM chave.

O grafo liga aparelho, sintoma, causa e peça. Use exatamente estes sete casos:
1. Dell G15 | desliga sozinho | pasta térmica de fábrica ressecada e aletas obstruídas | Pasta Térmica Alta Condutividade, Thermal Pads
2. Dell G15 | não liga | curto no circuito de carga (MOSFET de entrada) | MOSFET Canal N 30V, Carregador 130W
3. Acer Nitro 5 | tela azul | oxidação nos contatos da memória RAM | Limpa Contato Isopropílico, Memória DDR4
4. Acer Nitro 5 | tela preta | cabo flat da tela rompido ou solto na dobradiça | Cabo Flat EDP Nitro 5
5. MacBook Air | bateria não carrega | ciclos da bateria esgotados ou conector oxidado | Bateria Original A1466
6. Desktop | reinicia em jogos | fonte genérica sem potência suficiente | Fonte ATX 600W 80 Plus
7. Notebook | lentidão extrema | HD mecânico antigo com setores ruins | SSD NVMe 500GB ou SATA

Depois que um chamado é criado, faça o laudo em segundo plano: procure o aparelho e as palavras do relato no grafo.
- Se achar um caso: prioridade "alta" quando o relato tiver "não liga" ou "desliga", senão "media". Use a causa e as peças do caso.
- Se não achar: prioridade "media" e causa "necessário teste detalhado na bancada".
Guarde a prioridade e o laudo no chamado.

Crie também testes automáticos com pytest e me diga como rodar.

Teste no site

  1. Com a API ligada, abra o index.html do site.
  2. Preencha um chamado: equipamento Dell G15, relato "Esquenta muito e desliga sozinho quando eu jogo".
  3. Clique em Enviar chamado e anote o número.
  4. Em Acompanhar, digite o número e consulte.
Deu certo se o laudo mostrar prioridade ALTA, causa pasta térmica ressecada e as peças Pasta Térmica Alta Condutividade e Thermal Pads.
Se o laudo não aparecer na hora, espere 5 segundos e consulte de novo.
A API ou o site não responde? Veja se o terminal da API continua aberto. Se fechou, peça ao assistente: "Como eu ligo a API de novo?"
Deu erro ou travou? Copie a mensagem do terminal e escreva para o assistente: "Apareceu este erro. Explique em palavras simples e corrija passo a passo."
Comprovante: print do site mostrando o laudo do chamado.
7Criar a automação em Python

A automação é um segundo robô, de reserva. Ele procura chamados que ficaram sem laudo e completa.

Pedido da automação

Crie a automação em Python, um programa separado, de reserva.
A cada 5 segundos ela procura chamados SEM laudo e preenche o laudo usando a mesma triagem com grafo. Se não houver nenhum, escreve "Nenhum chamado pendente no momento". Deve parar com Ctrl + C.
Explique como ligar, em um terminal separado.
  1. Cole o pedido e aceite o que fizer sentido.
  2. Ligue a automação num segundo terminal, como o assistente explicar. Deixe a API ligada no primeiro.
Deu certo se aparecer Nenhum chamado pendente no momento a cada 5 segundos. Isso é normal: como a API já faz o laudo na hora, quase nunca sobra chamado sem laudo.
Para parar a automação: Ctrl + C.
Deu erro ou travou? Copie a mensagem do terminal e escreva para o assistente: "Apareceu este erro. Explique em palavras simples e corrija passo a passo."
Comprovante: print do terminal da automação rodando.
8Criar o agente CrewAI (a dupla de especialistas)

O CrewAI junta dois agentes de IA: um atendente e um técnico. Esta parte é opcional e mais difícil. Se travar, pule para o passo 9.

A) Pegar a chave do Gemini

  1. Abra aistudio.google.com com a sua conta Google.
  2. Procure a opção de criar uma chave de API e crie uma.
  3. Guarde a chave num papel. Não cole no chat do assistente.
A chave é só sua. Quem tem a chave usa a sua cota. Não mande para ninguém e não coloque em arquivo da pasta.

B) Pedir o agente

Pedido do agente CrewAI

Crie o agente CrewAI, com dois agentes que trabalham juntos:
- "atendente de triagem": entende o relato do cliente e diz a urgência.
- "técnico": sugere a causa provável e os próximos passos.

Use o Gemini como modelo. A chave deve vir da variável de ambiente GEMINI_API_KEY e NUNCA ser escrita em arquivo.
Só ligue o CrewAI se a variável MODELO_IA estiver definida. Se faltar chave ou der erro, volte para a triagem do grafo.

Me diga como instalar o CrewAI e como definir as variáveis no terminal, SEM eu colar a chave aqui no chat.

C) Definir a chave no terminal

No terminal onde a API vai rodar, digite (trocando a parte em maiúsculas):

$env:GEMINI_API_KEY="COLE_A_CHAVE_AQUI"

O assistente vai dizer qual valor colocar em MODELO_IA. A chave vale só para aquela janela do terminal.

A instalação do CrewAI demorou muito ou deu erro? É normal: ele é pesado. Avise o professor e siga para o passo 9. O projeto funciona sem ele.
Deu certo se o chamado voltar com um laudo escrito pelo agente, ou o programa voltar sozinho para o grafo se algo falhar.
Comprovante: print do terminal ou do site com o laudo do agente, ou um áudio dizendo onde travou.
9Criar o Rádio do Técnico (Telegram)

O bot manda os chamados para o seu celular e aceita comandos. Esta parte também é opcional.

A) Criar o bot (4 passos)

  1. No Telegram, procure @BotFather (com selo azul de verificado). Envie /start.
  2. Envie /newbot.
  3. Digite o nome da oficina. Depois um usuário que termine em bot.
  4. Ele mostra o token. Procure também @userinfobot, envie /start e anote o seu Id (um número).
  5. Abra a conversa com o seu bot e envie /start.
O token é a chave da sua oficina. Não mande para ninguém, não cole no chat do assistente e não tire print dele.

B) Pedir o código ao Gemini

Pedido do Telegram

Crie o aviso e os comandos do Telegram, sem biblioteca extra (use a API oficial por HTTP).
Quando chegar um chamado, avise o técnico com o laudo.
Aceite só comandos do chat do técnico: /abertos (lista a fila), /ver N (mostra o laudo), /andamento N e /concluir N.
O token e o número do chat vêm de variáveis de ambiente. Se não estiverem definidas, só escreva o aviso na tela e continue funcionando.
Explique como testar no meu computador, sem endereço público (buscando as mensagens do bot).

C) Dar o token ao programa

As informações vão para a janela do terminal, nunca para um arquivo. Digite (trocando as partes em maiúsculas):

$env:TELEGRAM_TOKEN="COLE_O_TOKEN_AQUI"
$env:TELEGRAM_CHAT_ID="COLE_SEU_ID_AQUI"
$env:TELEGRAM_SEGREDO_WEBHOOK="invente-uma-senha"

D) Testar no celular

Você enviaResultado
/abertosLista os serviços na fila
/ver 1Mostra o laudo do chamado 1
/andamento 1Marca como em andamento
/concluir 1Dá baixa: serviço entregue
O bot não responde? Veja: os programas estão ligados? A senha é igual onde o assistente mandou usar? O Id é o número do @userinfobot? Você enviou /start ao seu bot? As variáveis valem só para aquela janela do terminal.
Comprovante: foto do celular com /abertos e a resposta do bot (tape o token!).
10Ver tudo funcionando

Hora do teste de ponta a ponta. Confira cada item:

  1. A API está ligada (terminal mostra Uvicorn running).
  2. No site, você abre um chamado e recebe o número.
  3. O laudo aparece em Acompanhar, com prioridade e causa.
  4. Os testes passam (peça ao assistente: "Rode os testes e me diga o resultado.").
  5. Se fez o Telegram: o aviso chega no celular e os comandos funcionam.
Deu certo se as partes que você construiu conversam entre si: site, API, triagem e, se fez, automação, CrewAI e Telegram.
Compare com o gabarito: o projeto de referência do professor está no GitHub da oficina. O seu pode ficar diferente e estar certo. O que importa é cumprir a Especificação.
Próximo passo: levar a pasta para o GitHub. É a Etapa 6 do manual, a última do projeto.
Comprovante: foto ou print com o site mostrando um chamado e o laudo.

Regras de segurança

  • Senha, token e chave são seus. Não mande em conversa, foto, print ou no chat do assistente.

  • Leia antes de aceitar mudanças e comandos do assistente.
