Tutorial passo a passo

Monte o projeto no seu computador

Uma etapa de cada vez. Copie, cole e confira. Você é técnico de bancada em capacitação.

🔘 Faça⚠️ Cuidado💡 Dica✅ Deu certo se…🆘 Deu erro?📸 Comprovante
0 de 10 passos feitos
Você vai montar: um site onde o cliente abre um chamado → uma API que recebe → uma IA que diagnostica → um bot no Telegram que avisa o técnico.
Tempo: cerca de 2 horas, sem pressa. Precisa de: computador com Windows, internet e conta Google e conta no Telegram (a partir do passo 9).
⚠️ Terminal é a janela preta onde você digita comandos. Cada bloco preto abaixo tem o botão 📋 Copiar. Cole no terminal com botão direito do mouse e aperte Enter.
1Instalar o Python

O Python é a linguagem em que a API foi escrita. Você instala uma vez.

  1. 🔘 Abra python.org/downloads.
  2. 🔘 Clique no botão amarelo Download Python. Prefira a versão 3.12 (ou 3.11).
  3. Abra o arquivo baixado.
  4. ⚠️ Marque a caixinha "Add python.exe to PATH" (embaixo, na primeira tela).
  5. 🔘 Clique em Install Now. Espere terminar.

Agora abra o terminal: tecla Windows, digite PowerShell, Enter. Digite:

python --version
✅ Deu certo se aparecer algo como Python 3.12.10.
🆘 Disse "python não é reconhecido"? Você esqueceu a caixinha PATH. Rode o instalador de novo, escolha Modify e marque Add to environment variables. Feche e abra o PowerShell.
📸 Comprovante: print do terminal com a versão do Python.
2Baixar a pasta do projeto
  1. 🔘 Abra a pasta da oficina no GitHub.
  2. 🔘 Clique no botão verde <> Code → Download ZIP.
  3. Abra a pasta Downloads. Botão direito no ZIP → Extrair tudo → Extrair.
  4. Entre nas pastas até ver os itens api, site, notebooks e docs.
  5. 🔘 Entre na pasta api. Clique com o botão direito em um espaço vazio → Abrir no Terminal.
dir
✅ Deu certo se a lista mostrar main.py, db.py e requirements.txt.
💡 Esse terminal já está dentro da pasta api. Você não precisa digitar o caminho.
📸 Comprovante: print do terminal com a lista de arquivos.
3Instalar seu ajudante de código (Antigravity)

O Antigravity é um editor de código do Google com um assistente de IA. Ele lê os arquivos do projeto, explica o que cada um faz e ajuda a entender e corrigir erros.

⚠️ Antes de baixar, confira:
  • Você tem uma conta Google pessoal (de preferência @gmail.com). Conta de trabalho ou de escola pode dar problema.
  • Você tem 18 anos ou mais. Abaixo disso, o Antigravity não libera o uso.
  • Seu computador tem Windows 10 de 64 bits ou mais novo.
  • O Brasil está na lista de países liberados.

Instalar

  1. 🔘 Abra antigravity.google/download.
  2. 🔘 Escolha Windows (versão x64). Se a página mostrar mais de um produto, escolha o Antigravity IDE.
  3. Abra o arquivo baixado e siga as telas do instalador.
  4. Ao abrir o programa, entre com a sua conta Google.
  5. 🔘 Abra a pasta do projeto: procure no menu a opção de abrir pasta (em inglês: File → Open Folder) e escolha a pasta que você extraiu no passo 2.

Como pedir ajuda ao assistente

Abra o chat do assistente e escreva o pedido. Três pedidos prontos:

💬 Entender um arquivo

Explique, em palavras simples e para um iniciante, o que o arquivo api/main.py faz.

💬 Entender um erro

Apareceu este erro no terminal. Explique o que significa e como corrigir, passo a passo, para um iniciante:

COLE_O_ERRO_AQUI

💬 Mudar algo no site

Quero mudar o texto de um botão do site. Mostre em qual arquivo fica e como alterar. Explique antes de mexer em qualquer arquivo.
💡 Quando der erro em qualquer passo deste tutorial, copie a mensagem do terminal e peça ajuda ao assistente com o segundo pedido acima.

Cuidados

  • ⚠️ Leia antes de aceitar. O assistente pode propor mudar arquivos ou rodar comandos. Só aceite se você entender. Em dúvida, pergunte ao professor.
  • ⚠️ Nunca cole senha, token ou chave no chat do assistente. O que você escreve vai para o Google. Se for colar um erro, apague antes qualquer token que apareça nele.
  • O uso gratuito tem uma cota que renova toda semana. Se acabar, espere renovar.
  • Você pode desligar a coleta de dados nas configurações (Settings) do programa.
  • O assistente pode errar. Teste o que ele sugerir.
🆘 Não consegue usar o Antigravity (menos de 18 anos, país não liberado, conta de trabalho ou a cota acabou)? Sem problema: abra gemini.google.com, cole o erro ou o trecho do código e peça a explicação. Ou chame o professor.
📸 Comprovante: print do Antigravity com a pasta do projeto aberta e uma resposta do assistente.
4Montar a bancada (ambiente do Python)

Você cria uma caixa separada para as peças do projeto (ambiente virtual) e instala as peças (pacotes).

🖥️ Terminal 1 (o da pasta api):

python -m venv .venv
.venv\Scripts\activate
✅ Deu certo se aparecer (.venv) no começo da linha.
🆘 Erro "a execução de scripts foi desabilitada"? Rode isto, só nesta janela, e tente o activate de novo: 
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Agora instale as peças. Use esta opção (rápida, para a aula):

pip install fastapi uvicorn pytest httpx pydantic google-genai networkx matplotlib
✅ Deu certo se o terminal voltar para a linha com (.venv) sem a palavra ERROR.
💡 Pode demorar alguns minutos. Espere. Não feche a janela.
Opção completa: pip install -r requirements.txt instala também o CrewAI (a dupla de especialistas). É bem mais pesada e pode demorar muito. Só use se o professor pedir.
📸 Comprovante: print do terminal com (.venv) no começo da linha.
5Testar a bancada

O projeto tem testes prontos. Eles conferem se tudo está no lugar.

🖥️ Terminal 1:

pytest
✅ Deu certo se aparecer 5 passed em verde.
🆘 Disse "pytest não é reconhecido"? Falta o (.venv). Rode .venv\Scripts\activate de novo.
📸 Comprovante: print do terminal com 5 passed.
6Ligar a API (o coração da oficina)

A API recebe os chamados e pede o laudo da IA. Vamos ligar o Grafo de Conhecimento (a memória da oficina). Ele funciona sem internet e sem chave.

🖥️ Terminal 1:

$env:USAR_GRAFO="1"
uvicorn main:app --reload
✅ Deu certo se aparecer Uvicorn running on http://127.0.0.1:8000.
⚠️ Deixe este terminal aberto. Se fechar, a API desliga. Para parar de propósito: Ctrl + C.
💡 Quer ver a API por dentro? Abra no navegador http://localhost:8000/docs.
🆘 Disse que a porta 8000 está em uso? Outro programa usa essa porta. Troque por uvicorn main:app --reload --port 8001. No site (passo 7), clique em ⚙️ Alterar e digite http://localhost:8001.
📸 Comprovante: print do terminal com Uvicorn running.
7Abrir o site e mandar o primeiro chamado
  1. Na pasta do projeto, abra a pasta site.
  2. 🔘 Dê dois cliques em index.html. O navegador abre o site.
  3. Veja o topo: a bolinha deve estar verde (API Online).
  4. 🔘 Desça até Abrir Novo Chamado. Clique no botão rápido "Dell G15 desligando em jogos". O formulário se preenche sozinho.
  5. 🔘 Clique em Enviar Chamado para Triagem IA. Anote o número do chamado.
  6. 🔘 Desça até Acompanhar. Digite o número e clique em Consultar Status.
✅ Deu certo se o painel mostrar prioridade ALTA e a causa pasta térmica ressecada, com as peças Pasta Térmica Alta Condutividade e Thermal Pads.
💡 Olhe o Terminal 1. Aparece [telegram desligado] com o aviso. É normal: o bot ainda não foi ligado (passo 9).
Se o laudo não aparecer na hora, espere 5 segundos e consulte de novo.
🆘 A bolinha está vermelha (API Offline)? O Terminal 1 fechou ou parou. Volte ao passo 6. Se usou outra porta, clique em ⚙️ Alterar no site.
📸 Comprovante: print do painel de diagnóstico com prioridade e peças.

9Ligar o Rádio do Técnico (Telegram)

O bot manda os chamados para o seu celular e aceita comandos.

A) Criar o bot

  1. 📲 No Telegram, procure @BotFather (selo azul ✔️). Envie /start.
  2. Envie /newbot.
  3. Digite o nome da oficina. Depois um usuário que termine em bot.
  4. Ele mostra o token (um texto longo, parecido com 7123456789:AAH...).
  5. Procure @userinfobot, envie /start e anote o seu Id (um número).
  6. 🔘 Abra a conversa com o seu bot e envie /start. Sem isso ele não consegue falar com você.
⚠️ O token é a chave da sua oficina. Não mande para ninguém, não poste no Classroom, não tire print dele.

B) Dar o token à API

As informações vão para a janela do terminal. Não use o arquivo .env: o projeto não lê esse arquivo.

🖥️ Terminal 1 — pare a API (Ctrl + C) e rode, trocando as partes em MAIÚSCULAS:

$env:USAR_GRAFO="1"
$env:TELEGRAM_TOKEN="COLE_O_TOKEN_AQUI"
$env:TELEGRAM_CHAT_ID="COLE_SEU_ID_AQUI"
$env:TELEGRAM_SEGREDO_WEBHOOK="invente-uma-senha"
uvicorn main:app --reload

C) Ligar a ponte do bot

Abra um segundo terminal: de novo na pasta api (botão direito → Abrir no Terminal).

🖥️ Terminal 2 — use a mesma senha do Terminal 1:

.venv\Scripts\activate
$env:TELEGRAM_TOKEN="COLE_O_TOKEN_AQUI"
$env:TELEGRAM_SEGREDO_WEBHOOK="invente-uma-senha"
python bot_local.py
✅ Deu certo se o Terminal 2 mostrar Repassando mensagens do bot para a API local.

D) Testar no celular 📲

No Telegram, na conversa com o seu bot, envie:

Você enviaResultado
/abertosLista os serviços na fila
/ver 1Mostra o laudo da IA do chamado 1
/andamento 1Marca como em andamento
/concluir 1Dá baixa: serviço entregue
🆘 O bot não responde?
  • Os 2 terminais estão abertos e ligados?
  • A senha é igual nos dois?
  • O Id é o número do @userinfobot, e não o nome?
  • Você enviou /start ao seu bot?
Variáveis valem só para aquela janela. Se fechou o terminal, rode tudo de novo.
📸 Comprovante: foto do celular com /abertos e a resposta (tape o token!).
10O grande teste (e o robô opcional)

Teste de ponta a ponta

  1. No site, abra um novo chamado (o botão rápido serve).
  2. 📲 No celular, o bot avisa com o laudo da IA.
  3. 📲 Envie /abertos, depois /ver 2 (use o número do seu chamado).
  4. 📲 Envie /andamento 2.
  5. No site, consulte o número: o status virou EM ANDAMENTO.
  6. 📲 Envie /concluir 2 para dar baixa.
✅ Deu certo se o celular e o site mostrarem o mesmo status.

Robô opcional: a automação

É um segundo robô que procura chamados sem laudo. Como a API já faz o laudo na hora, ele quase sempre vai dizer Nenhum chamado pendente. Isso é normal.

🖥️ Terminal 3 (pasta api):

.venv\Scripts\activate
python automacao_chamados.py --continuo --intervalo 5
✅ Deu certo se aparecer Buscando novos chamados pendentes... a cada 5 segundos. Para parar: Ctrl + C.
📸 Comprovante final: foto do celular com /ver e print do site com o status do mesmo chamado.
