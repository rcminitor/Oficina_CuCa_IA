Abra o PowerShell no seu computador e cole os comandos abaixo:

cd "$env:USERPROFILE\Downloads\oficina-digital\api"
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload

✅ Quando aparecer Uvicorn running on http://127.0.0.1:8000, a bolinha no topo ficará verde e esta etapa será marcada automaticamente!

▼

Abra um terceiro terminal no PowerShell e ative a automação em segundo plano:

cd "$env:USERPROFILE\Downloads\oficina-digital\api"
.venv\Scripts\activate
