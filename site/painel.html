Sua API

Verificando...

A API está desligada? Ligue a API do Passo 5 do tutorial e deixe o terminal aberto. O endereço padrão é http://localhost:8000.

Ela está ligada, mas o painel diz offline? O navegador pode bloquear uma página da internet de falar com o seu computador. Nesse caso, use o site que você criou no Passo 4.

Como usar

1. Ligue a API

Deixe o terminal da API aberto. Quando ela estiver ligada, a bolinha fica verde.

2. Abra um chamado

Preencha o formulário ou clique em um caso de exemplo. Anote o número.

3. Acompanhe

Digite o número e veja a prioridade e o laudo da triagem.
