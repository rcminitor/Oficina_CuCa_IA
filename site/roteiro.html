Antes de começar

Separe estas coisas. Sem elas, alguns passos travam.

Computador

Windows 10 de 64 bits ou mais novo, com internet. Mac e Linux: veja o quadro mais abaixo.

Conta Google

Pessoal, de preferência @gmail.com, com 18 anos ou mais. Serve para Antigravity, NotebookLM, Colab e AI Studio.

Celular

Com o Telegram instalado. Só é preciso nos passos opcionais.

Fone de ouvido

Para o resumo em áudio do NotebookLM.

Tempo total: cerca de 6 horas, em várias aulas. Os passos 11 e 12 são opcionais e somam uma hora e vinte minutos.

O NotebookLM acompanha você

Depois da Etapa 2, deixe o seu caderno do NotebookLM aberto numa aba. Cada passo do Tutorial traz uma pergunta pronta para ele, no quadro "Ouça no NotebookLM". Use antes de pedir ao Gemini e depois, para conferir. Ele responde só com os documentos do projeto.

Se travar

Não tenho permissão de administrador

Em computador da escola, o instalador pode pedir uma senha que você não tem. Faça assim:

  1. Python: no instalador, escolha Customize installation e desmarque Install for all users. Ele instala só para você e não pede administrador.
  2. Git: no instalador, escolha a opção de instalar só para o seu usuário, se ela aparecer.
  3. Antigravity: na página de download, procure a versão para o usuário atual, se houver.
  4. Continuou pedindo senha? Não tente contornar. Chame o professor. Ele pode liberar a instalação ou indicar outro computador.

Uso Mac ou Linux

O site foi escrito para Windows, mas o projeto roda nos três sistemas. As diferenças são pequenas:

No WindowsNo MacNo Linux
Terminal: PowerShellTerminal: abra o app Terminal (Cmd + Espaço, digite Terminal)Terminal: o do seu sistema (em geral Ctrl + Alt + T)
python --versionpython3 --versionpython3 --version
Print: Windows + Shift + SPrint: Cmd + Shift + 4Print: tecla Print Screen

Nos pedidos prontos, troque a frase "para Windows" por "para Mac" ou "para Linux". O Gemini ajusta os comandos. Se um comando falhar, mostre o erro ao professor.

Não consigo usar o Antigravity

Menos de 18 anos, país não liberado ou conta de trabalho? Use o Gemini em gemini.google.com. Peça o código lá, salve nos arquivos da sua pasta e siga o resto igual. Avise o professor.

A cota do Gemini acabou

O uso gratuito renova toda semana. Espere renovar, ou continue pelo gemini.google.com.

O assistente deu uma resposta estranha

A IA pode errar. Peça: "Explique de novo, em palavras simples." Em dúvida, pergunte ao professor.
